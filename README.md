# bc_converter
Converts my Bandcamp files.

Usage: bc_convert.py [-h] --file FILE [--output OUTPUT] [--remove]

Extract and organize audio files by metadata.

options:
  -h, --help       show this help message and exit
  --file FILE      Path to ZIP file containing audio files.
  --output OUTPUT  Destination root directory.
  --remove         Delete the ZIP file after conversion.
